## Design Context

### Users

Small fleet owners, logistics companies, and transport operators who need dependable real-time vehicle visibility, clear trail history, and straightforward fleet administration without enterprise complexity. The primary landing-page job is to help a qualified operator understand the product quickly and request a demo.

### Brand Personality

Premium, modern, calm, and operationally confident. Use precise language and concrete outcomes rather than hype. The experience should evoke control, trust, and clarity.

### Aesthetic Direction

Premium/modern light interface built on the existing FleetTracker green visual system. Favor editorial typography, generous whitespace, restrained earth-and-green accents, crisp map-inspired line details, and purposeful depth. Avoid generic SaaS gradients, noisy dashboards, excessive rounded cards, and overly technical jargon.

### Implementation Defaults

Use the detected React 19 + Vite + TypeScript stack, React Router, and the existing vanilla CSS system. Preserve the existing authentication and fleet application surfaces. No component library, form library, table library, or visualization library is currently established beyond MapLibre for maps. New public marketing UI should use semantic HTML, responsive CSS, accessible controls, and lightweight inline SVG/CSS decoration.

### Design Principles

- Establish hierarchy with typography, spacing, and contrast before decoration.
- Make one conversion action obvious: request a demo.
- Show operational confidence through concrete workflows and proof-like product details, not invented customer claims.
- Use premium restraint: warm neutrals, deep green, one warm accent, and selective elevation.
- Keep public marketing content indexable and answerable while keeping the authenticated app focused and task-oriented.
